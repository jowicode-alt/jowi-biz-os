The selected group is recorded with this programme session. Active programme enrolment, course-unit registration, campus, study year and semester determine student eligibility.

Select multiple study years and semesters for one shared session. All selected combinations use the same QR code and six-digit code. Use Ctrl/Command or tap multiple options on supported devices.

Groups are loaded from Academic Setup for the selected campus. Combined sessions include all matching groups; separate sessions use the selected group.

A combined session can include learners from different programmes, study years and semesters using one QR code and six-digit code, provided they share the same course unit, campus and academic year. Choose separate session by session group when attendance should be restricted to the selected group (for example, Morning, Evening or Weekend). Selected study years and semesters still determine which learners are eligible. These details are checked again when learners check in.
